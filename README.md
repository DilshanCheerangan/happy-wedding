# Happy Wedding

A front-end wedding website project focused on presenting a wedding celebration through an interactive, responsive digital experience.

## What it is for

The project demonstrates how a personal event website can combine visual storytelling, responsive layouts, and interactive web elements into a polished single-page experience.

## Project status

This is a front-end project. See the source files for the current design and implementation.
